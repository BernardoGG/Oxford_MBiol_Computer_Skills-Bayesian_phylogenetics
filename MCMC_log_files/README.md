This folder contains the log files from the BEAST runs performed ahead of the practical. The files have been converted to .csv format to facilitate their importation into the R environment.

- `CHIKV_IndianOcean_BEAST_output_log.csv` — guide / practical MCMC log (Kassala outbreak TMRCA/age).
- `CHIKV_IndianOcean_updated_BEAST_output_log.csv` — assessment log aligned to `MCC_CHIKV_IndianOcean_2019hypotheticaloutbreak.tree`, with additional `mrca(HypA)`, `age(HypA)`, `mrca(HypB)`, and `age(HypB)` columns.
